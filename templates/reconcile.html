Union-merges keywords from every Used:...-tagged clip in the current project into the matching clips of another project, never dropping a keyword either side already has. Clips are matched by filename + frame count, not file path or file timestamps (timestamps can silently drift during backups/ingest across timezones), so this still works correctly for clips Resolve copied into the project bundle (media management), where the on-disk path no longer matches the original. This switches Resolve's active project to the target and back while it runs, searching every known database if needed.
